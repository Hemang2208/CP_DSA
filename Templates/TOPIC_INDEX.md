## Notes

- Theoretical and specialised topics such as NP-completeness, linear programming, advanced geometry, and complex data structures are represented by runnable fundamentals or closely related templates rather than full production implementations.
- Every template is standalone CommonJS and can be run with `node "File.js" < "Input.txt" > "Output.txt"`.
- See `README.md` for per-folder file tables, techniques, and complexity notes.
